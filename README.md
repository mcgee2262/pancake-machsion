# Pancake Machsion

A responsive homepage for **Pancake Machsion**, a fictional luxury breakfast spot with a friendly diner soul.

## ▶️ [Open the live site](https://mcgee2262.github.io/pancake-machsion/)

Runs on GitHub Pages. To preview locally, open `index.html` in any browser. No build step needed.

## Edit the content

Everything editable lives in the `SITE` object near the bottom of `index.html`:

- **Menu:** `SITE.menu` (categories and items) and `SITE.favorites` (the three featured cards)
- **Hours:** `SITE.hours`
- **Contact placeholders:** `address1`, `address2`, `phone`, `email`, `reservations`, `events`
- **Social links:** `SITE.social`

## Notes

- Address, hours, phone, and social links are placeholders.
- The reservation and contact forms are front-end only and don't send anything yet.
- Scroll effects (parallax windows and line-by-line headline reveals) turn off for visitors who prefer reduced motion.
- Design work follows the `apple-ui-designer` skill in `.claude/skills`.
